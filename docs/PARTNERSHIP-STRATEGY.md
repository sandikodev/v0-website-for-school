# Partnership Strategy - AkseSekolah.id

## 🎯 Core Philosophy

**"Collaborate, Don't Compete"**

AkseSekolah.id percaya pada kekuatan partnership untuk memberikan value terbaik kepada sekolah.

---

## 🤝 Key Partnerships

### 1. Awan Kinton (Infrastructure Partner)

#### About
- **Company**: PT Koneksi Jaringan Indonesia (Koneksi Cloud)
- **Service**: PaaS (Platform as a Service)
- **Role**: Infrastructure & hosting provider
- **Organization System**: GitHub-style organizations for schools

#### Partnership Model
```
AkseSekolah.id runs on Awan Kinton infrastructure

Benefits:
✅ Reliable & scalable infrastructure
✅ Local data center (Indonesia)
✅ Competitive pricing for schools
✅ Integrated billing & provisioning
✅ Enterprise-grade support
```

#### Value Proposition for Schools
```
Buy hosting via AkseSekolah.id (powered by Awan Kinton):
- Cheaper: Rp 300k/year vs Rp 650k/year
- Easier: 5-minute setup vs 2-3 days
- Integrated: One dashboard for everything
- Supported: Local support in Bahasa Indonesia
- Reliable: Enterprise infrastructure
- Organization: GitHub-style team management
- Automatic: Organization created seamlessly
```

#### Organization System (Like GitHub)
```
Awan Kinton Organizations:
- Organization = School/Institution
- Members = Teachers (verified via guru.belajar.id)
- Resources = Shared (storage, bandwidth, services)
- Billing = Centralized
- Permissions = Role-based

Benefits:
✅ Teachers can join existing organization
✅ Shared resources & volume discounts
✅ Centralized management
✅ Professional structure
✅ Easy collaboration
```

#### Revenue Model
```
School pays → AkseSekolah.id → Revenue share → Awan Kinton

Example:
- School pays: Rp 300,000/year
- AkseSekolah.id keeps: Rp 100,000 (33%)
- Awan Kinton gets: Rp 200,000 (67%)

Win-win-win:
- School: Better price & service
- AkseSekolah.id: Additional revenue
- Awan Kinton: New customers
```

### 4. Belajar.id / Kemendikbud (Verification Partner)

#### About
- **Platform**: Belajar.id (Government email system)
- **Owner**: Kemendikbud (Ministry of Education)
- **Purpose**: Official email for Indonesian education ecosystem

#### Integration Model
```
Email Verification System:
- Teacher email: nama@guru.{schooltype}.belajar.id
- Student email: nama@{schooltype}.belajar.id (not allowed)
- Verification: Automatic via email domain
- Trust: Government-backed authentication
```

#### Email Pattern
```
Valid (Teacher):
✅ john@guru.smp.belajar.id
✅ jane@guru.sd.belajar.id
✅ admin@guru.sma.belajar.id
✅ kepala@guru.smk.belajar.id

Invalid (Student):
❌ student@smp.belajar.id (no "guru" subdomain)
❌ siswa@sd.belajar.id (no "guru" subdomain)
```

#### Benefits
```
For AkseSekolah.id:
✅ Automatic verification (no manual process)
✅ Trusted authentication (government-backed)
✅ Fraud prevention (cannot fake)
✅ Scalable (all schools in Indonesia)

For Schools:
✅ Easy registration (use existing email)
✅ No additional verification needed
✅ Trusted by Kemendikbud
✅ Professional email system

For Awan Kinton:
✅ Verified organizations
✅ Reduced fraud risk
✅ Government alignment
✅ Education sector focus
```

#### Registration Flow
```
1. Teacher enters: john@guru.smp.belajar.id
   ↓
2. System validates email pattern
   ↓
3. Extract school type: SMP
   ↓
4. Check Awan Kinton: Organization exists?
   ↓
   ├─ YES → Join existing organization
   └─ NO → Create new organization
   ↓
5. Request school details (NPSN, address, etc.)
   ↓
6. Auto-create organization at Awan Kinton
   ↓
7. Done! School account ready
```

#### Future Collaboration
```
Potential partnerships with Kemendikbud:
- Official endorsement
- Integration with school database
- Bulk deployment to schools
- Government subsidy programs
- National digitalization initiative
```
